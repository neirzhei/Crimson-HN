A Chrome extension that transforms Hacker News into a read-only, dark OLED interface.

### Feature
* OLED dark theme.
* Read-only layout that removes voting controls, input forms, and footer clutter.
* Restructured story feed with card-based layouts and domain badges.
* Interactive, collapsible comment threads.

### Installation
1. Clone or download this repository.
2. Open `chrome://extensions` in your Chromium-based browser.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the project folder.
